# On-call and support

- On-call owns the kill switches: uploads, extraction, generation, shares, and each rule
  version.
- First response: confirm scope, stop the bleeding, preserve evidence, then investigate.
- Never ask a user to email a document. Use the consented concierge reviewer workflow.
- Never open raw documents in support tooling; use the case grant, audit trail, and
  no-download rule.
- Escalate privacy incidents to the DPO and security incidents to the Incident Commander
  immediately.
- Close with: affected IDs (hashed), containment, correction, notification decision, and
  follow-up owner.
